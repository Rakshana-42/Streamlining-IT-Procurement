Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

Submitted by: Rakshana A 

Project Description

This project demonstrates how ServiceNow Flow Designer can be used to automate standard laptop orders. When a standard laptop request is approved, the Flow automatically creates a Catalog Task and assigns it to the Hardware group.
